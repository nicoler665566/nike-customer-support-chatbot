# Nike Customer Support Chatbot

Explore conversational retail support through product recommendations and order-related actions.

## Technical approach

Use Rasa flows and custom Python actions, embedding-based product recommendation and image-related order checks.

## Technologies

Rasa, Python, YAML, embeddings

## Project materials

- `Public/actions/data/org-chart-sample.pdf`

## Getting started

Inspect the Public/ application and original dependency/command files if present. Local demo account/order databases and credentials were withheld; replacement fixtures and configuration are required. Third-party product images require permission before publication. This is an academic prototype, not an official Nike product.

For notebooks, use a compatible Python/Jupyter environment and install the imported libraries. Original environment-specific paths may need local adjustment.
